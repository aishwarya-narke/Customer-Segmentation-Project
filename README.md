# Customer Segmentation Project

## Overview
This project uses K-Means clustering to segment customers based on income, spending behavior, age, and gender.

## Features
- Customer clustering using Python (scikit-learn)
- Analysis of customer demographics and spending patterns
- Visualization of customer segments

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## How to Run
1. Install required libraries:
   pip install pandas matplotlib scikit-learn

2. Run the project:
   python main.py

## Output
- Clustered customer segments
- Visual graphs showing customer groups
- Insights into high-value and low-value customers
